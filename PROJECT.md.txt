# Before Your Buy

สร้างเว็บแอปช่วยวางแผนการเงินก่อนซื้อสินค้า โดยใช้ React + Vite สำหรับ Frontend และ Node.js + Express สำหรับ Backend

## Main Feature
Purchase Readiness Check: ผู้ใช้กรอกชื่อสินค้า ราคา เงินที่มี และค่าใช้จ่ายจำเป็น ระบบคำนวณเงินคงเหลือ พร้อมแสดงผลว่าอยู่ในงบหรือเกินงบ

## Supporting Features
- แสดงเงินคงเหลือและเปอร์เซ็นต์ราคาสินค้าเทียบกับเงินที่มี
- ปุ่มทดลองกรอกข้อมูลและปุ่มรีเซ็ต
- ตรวจสอบข้อมูลผิดพลาด
- รองรับมือถือและคอมพิวเตอร์
- ใช้ภาษาไทยและสกุลเงินบาท

## Tech Stack
- React + Vite
- Node.js + Express
- API: POST /api/check-budget
- Frontend: port 5173
- Backend: port 3001

## Requirements
- สร้างโค้ดที่ใช้งานได้จริงครบทุกไฟล์
- ตั้งค่า npm run dev ให้เปิดทั้ง Frontend และ Backend พร้อมกัน
- ใช้ concurrently สำหรับรันทั้งสองระบบ
- ไม่ต้องมีระบบล็อกอินหรือฐานข้อมูล
- ใช้ UI ที่สะอาด ทันสมัย และ Responsive
- ตรวจสอบข้อมูลทั้ง Frontend และ Backend
- ห้ามเว้น TODO สำหรับฟีเจอร์หลัก

คำสั่งเริ่มต้น:

npm install
npm run dev

หลังสร้างเสร็จ ให้อธิบายวิธีติดตั้งและรันโปรเจกต์
